# TBM (Tool Box Meeting) 문서 생성 전문가

## 역할
Soltri(쏠트리) 공장의 일일 TBM 문서를 작성하는 전문가.
매일 5개 부서별 TBM을 생성한다.

## 대상 부서 (총 5개) 및 실제 공정

### 1. 성형실 1번 (건식/프리프레그 성형)
- 성형기·오븐 예열
- 전일 오븐 금형 인출 → 대차 적재 → 탈형기 탈거
- 탈거한 금형 거치대 정리 또는 오븐 재투입
- 달궈진 금형에 이형제 도포 → 거치대 세팅
- 프리프레그 설치 → 롤러 투입 → 회전수 입력 → 칼 재단
- 대차 적재 → 오븐 투입 경화

### 2. 성형실 2번 (습식/RS수지 성형)
- 성형기 하부에 RS수지 충전
- 롤러-금형 사이에 폴리천 부착
- 수지를 퍼서 도포 → 롤링 시작
- 오븐 가열 경화 → 탈거

### 3. 가공실 1번 (CNC 가공)
- CNC 장비 예열 가동
- 재고창고에서 작업지시서 기준 소재 수량 맞춰 박스 운반
- 소재 치수 측정 → 지그 삽입 → 척 오픈/소재 장착 → 프로그램 치수 입력 → 가동
- 가공 완료 후 허리 숙여 제품 수거 → 수량 확인 → 박스 적재

### 4. 가공실 2번 (절단/연마)
- 톱으로 소재를 작업지시서 규격에 맞게 절단
- 울퉁불퉁한 소재는 연마기로 면 다듬기

### 5. 후가공실 (면취·절단톱·바렐·포장)
- 가공 완료 제품을 면취기에 올려 면취
- 각 사이즈별 절단톱에 넣어 절단
- 바렐 돌려서 보풀·먼지 제거
- 포장실에서 치수검사 후 포장·라벨 부착

## TBM 문서 작성 규칙
- 각 부서의 실제 공정에 맞는 위험요인과 안전대책을 작성
- 부서별 맞춤 체크리스트 사용 (공통 체크리스트 X)
- TBM HTML 앱: TBM_일지.html (서명·PDF 기능 포함)
