# O0852 CNC 매크로 프로그램 교육자료

## 1. 전체 요약

**O0852는 CNC 선반(Turning)에서 링형 부품(부싱/베어링류)을 자동으로 연속 가공하는 FANUC 매크로 프로그램입니다.**

소재 파이프를 척에 물린 뒤, 단면절삭 → 스텝절삭(황삭/정삭) → 챔퍼가공 → 절단을 반복하며, 소재가 부족해지면 오토링크(자동 소재 인출)로 소재를 당겨서 다시 가공을 이어갑니다.

---

## 2. 프로그램 구조 (4개 서브프로그램)

```
O0852 (메인 셋업)          ← 파라미터 입력, 검증, 기계 설정
  └─ M98 P9001             ← 서브 호출
      O9001 (메인 로직)    ← 계산, 알람 체크, 가공 시작
        └─ M98 P9002       ← 서브 호출
            O9002 (메인 가공) ← 실제 절삭 사이클 (면삭→스텝→챔퍼→절단→반복)
              └─ M98 P9003 ← 서브 호출
                  O9003 (잔재 가공) ← 소재 인출 후 남은 부분 가공
```

## 3. O0852 상세 분석 — 메인 셋업 프로그램

### 3-1. 프로그램 시작과 초기화 (Line 1~3)

```
%                          ← 프로그램 시작 기호
O0852(JOB_SETUP);          ← 프로그램 번호와 이름
GOTO 9000;                 ← ⭐ 첫 실행 시 N9000(변수 초기화)으로 점프
```

> **핵심 포인트**: 프로그램을 처음 실행하면 바로 N9000으로 가서 모든 변수를 -9999로 초기화한 뒤, 다시 N10으로 돌아옵니다. 이렇게 하면 이전 작업의 값이 남아있는 사고를 방지합니다.

### 3-3. 소재별 이송속도 자동 설정 (Line 32~64)

```
IF [#105 EQ 1] GOTO 6010  ← CN 소재면 6010으로
IF [#105 EQ 2] GOTO 6020  ← RS 소재면 6020으로
IF [#105 EQ 3] GOTO 6030  ← CM 소재면 6030으로
GOTO 6040                  ← 그 외 기본값
```

| 소재 | #124 (황삭) | #125 (스텝) | #126 (챔퍼) | #127 (절단) |
|------|------------|------------|------------|------------|
| CN | 0.15 | 0.12 | 0.15 | 0.09 |
| RS | 0.13 | 0.08 | 0.05 | 0.08 |
| CM | 0.13 | 0.09 | 0.09 | 0.09 |
| 기타 | 0.15 | 0.10 | 0.10 | 0.10 |

> 예: T01 CN소재 황삭 → F = 1700 × 0.15 = 255 mm/min

### 3-5. 안전 체크 — RS40/소경 소재 (Line 87~94)

```
#129=0                         ← 잔재 보정값 초기화
IF [#105 EQ 2] GOTO 2900      ← RS40 소재면 안전모드
IF [#109 LT 30] GOTO 2900     ← 외경 30mm 미만이면 안전모드
N2900 #129=15                  ← 잔재 보정값을 15mm로 강제 설정
```

> RS40 소재나 소경 소재는 강성이 약하므로, 잔재 보정값을 15mm 추가하여 안전 마진을 확보합니다.

### 3-6. 입력값 검증 (Line 95~138)

모든 변수가 -9999(미입력 상태)인지 하나씩 체크합니다.
빠진 값이 있으면 해당 알람 번호로 점프하여 **#3000 알람**을 발생시킵니다.

예시:
- `#101 = -9999` → 알람 101번: "NO #101 MAT OO" (소재 길이 끝자리 미입력)
- `#113 > 40`이고 `#119 ≠ 1` → 알람 119번: "LEN>40! SET #119=1" (긴 부품 확인 필요)

## 4. O9001 상세 분석 — 메인 로직

### 4-1. 전체 길이 및 개수 계산 (Line 291~313)

```
#140 = #101 + #102 - #129       ← 전체 소재 길이 (안전 보정 적용)
#505 = #113 + #114              ← 1개당 가공 단위 = 완성길이 + 절단폭
                                   예: 7.823 + 2.02 = 9.843mm

#602 = FIX[(#103 - #530) / #505]  ← 척 유효길이 내 가공 가능 개수
#103 = (#602 × #505) + #530       ← 척 길이를 정수 배수로 재조정

#500 = #103 - #530              ← 유효 가공 길이
#517 = FIX[#500 / #505]         ← 1회 인출당 가공 개수
#518 = #517 × #505              ← 1회 인출당 총 가공 길이
```

> **현재값 계산 예시**:
> - #505 = 7.823 + 2.02 = 9.843mm
> - 유효길이 = 75 - 12 = 63mm
> - #517 = FIX[63 / 9.843] = **6개** (1회 인출당)
> - #518 = 6 × 9.843 = 59.058mm

### 4-2. 알람 체크 (Line 315~369)

| 알람번호 | 조건 | 의미 |
|---------|------|------|
| 1 | #140 > 580 | 소재 길이 580mm 초과 |
| 2 | #109 < #111 | 소재 외경이 완성 외경보다 작음 |
| 3 | #110 > #112 | 소재 내경이 완성 내경보다 큼 |
| 4 | #125 ≥ 0.14 | T01 스텝 이송 과대 |
| 5 | #102가 0/100/200/300/400/500 아님 | 백자리 단위 오류 |
| 6 | #101 > 99 | 끝자리 99 초과 |
| 7 | #140 ≤ #103 | 소재 길이 부족 |
| 10 | #104 > 40 | 초기 면삭량 40 초과 |
| 203 | #109 ≤ #110 | 소재 외경 ≤ 소재 내경 |
| 204 | #111 ≤ #112 | 완성 외경 ≤ 완성 내경 |

## 6. O9003 상세 분석 — 잔재 가공

오토링크 횟수를 모두 사용한 후 남은 소재를 처리합니다.

```
#540 = 남은 가공 가능 길이 (정수 배수)
```
